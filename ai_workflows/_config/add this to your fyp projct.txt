## 5. Scheduler Settings

Under **System Settings**, add:

```
Scheduler Settings

Administrator Can Configure

• Academic Session Start Date

• Semester Duration (e.g., 6 Months)

• Automatic Promotion

Enable / Disable

• Promotion Date

• Automatic Database Backup

• Backup Time

• Automatic Log Cleanup
```

---

### One recommendation

Instead of hardcoding "every six months," make it **configurable**. For example:

* Semester Duration: **6 months**
* Promotion Date: **1 January 2027**
* Automatic Promotion: **Enabled**

That way, if your university changes its academic calendar in the future, the administrator only changes the settings—no code changes are needed.
